# Detection Engineering Data Dictionary

| Field Name | Description |
| :--- | :--- |
| EventID | Identifies the specific Windows Security or Sysmon event type |
| RecordNumber | Sequential log record number within the event source |
| ProviderGuid | Unique identifier for the event provider generating the log |
| SourceName | Event log source such as Sysmon or Windows Security Auditing |
| DestinationPort | Target network port involved in a connection |
| Image | Full executable path of the process |
| CommandLine | Command-line arguments passed when starting a process |
| ParentImage | Executable path of the parent process that spawned the process |
